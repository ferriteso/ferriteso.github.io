# ferriteso.github.io

The Ferrite website. React + Vite, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

- `src/pages/`: Home, Clusters, Hardware, Company
- `src/components/`: nav, footer, logo and the animated canvases
- `public/brand/`: logo files and avatars
- `public/social/`: LinkedIn, X, GitHub and Open Graph images
